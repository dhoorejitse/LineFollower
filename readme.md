## specifications

microcontroller: ESP32 NodeMCU Dev Board

motors: Aslong JGA12-N20-30 6V

h-bridge: DRV8833 H-Bridge Module

sensors: HY-S301

batteries: 2x18650

wireless communication: CP2102 (μC)

distance sensor - motors: ~10CM

weight: 185g

speed: 0.5m/s
